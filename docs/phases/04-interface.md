# M4 — Web UI, API và CLI

## Công việc

Danh sách dự án; nhập kịch bản; chỉnh cảnh/audio; render progress; xem video; review; export/import; CLI cho tái tạo.

## Kiểm thử và lỗi có chủ đích

Browser create/edit/render/review/download; HTTP body/error/path; CLI smoke; form trạng thái lỗi.

## Cổng nghiệm thu

Luồng end-to-end sử dụng được từ giao diện và CLI.

## Khi chưa đạt

Lưu input/log; sửa nguyên nhân; chạy lại ca lỗi và regression liên quan. Không ghi DONE trước khi có bằng chứng. Kết quả thực tế cập nhật trong docs/verification.md và plan.md.
