## Architecture: additive opt-in performance layer; preserve validated v1

**Design rule:** Preserve general-playback/1, general-film/1, the raw physics solver and v1 sample functions unmodified wherever possible. Add a separately versioned data-only G3 performance document with content hash and validated authored event intervals. Proposed boundary:

  G3 baseline playback (immutable grip/prop/camera/physics/release contracts)
    + performance-plan/1 (explicit actor id, clip interval, intent, bounded pose channels)
    -> validated performance sampler (pure function of exact frame and pinned sources)
    -> rig solve with held-world-contact anchor / planted-sole constraints
    -> QA per frame (actual sprite art, z, contact, bounds, camera, continuity)
    -> unchanged source-bound native renderer -> new independent artifact/media audit.

Do **not** use a mutable per-frame integrator or wall-clock timers. In a G3 scene containing a released prop, sampler must reference the verified physics bake as read-only, retaining its exact centers, angles and contact events; post-release body performance may affect the actor but cannot drive the falling prop.
- Proposed strict schema performance-plan/1: schemaVersion, baselinePlaybackSha256, artManifestSha256, tracks keyed by unique actor IDs, each with authored intent/phase intervals (prepare, reach/lift, hold, release, recover/settle), grounded event boundaries, target gaze/head/torso/hip/free-hand parameters in explicit bounds, deterministic ease names, optional per-actor amplitude. Release frame comes from original validated GeneralRelease, not duplicated as a conflicting editable value. Optional camera intent is a distinct validated track and cannot change the physics support surface.
- Inputs fail closed on missing/mismatched actor, asset/revision, unsupported capability, duplicate/overlapping invalid events, nonfinite values, impossible IK, excessive pose or camera jump, timebase conflict, outside-frame cue or stale bake. No fallback to M2 or baseline disguised as enhanced. Preserve held contact and soles in world-space within existing <0.001px tolerance; release starts from same last-held center (existing <1e-5 target) and per-frame full-frame sprite-art QC still applies.
- Apply pose only through existing actorSprites rig interfaces, recomputing shoulder/elbow feasibility and actual hand prop anchor after body shift. If the optional performance pose cannot satisfy existing IK and contact, back off **only the optional performance contribution** deterministically with bounded search, keep baseline anchor and foot locks, record backoff as an explicit warning and a frame for visual review. Do not change bone lengths or hide IK errors. For after-release, preserve existing authored wrist retreat, then add bounded torso/head/free-hand reaction around that verified wrist trajectory.
- Composition: existing painter-order shadowbox, camera and silhouettes are authoritative; optional very subtle grounded secondary shadow, parallax/background emphasis and camera push only if pinned to actual shapes/anchors and world-space contacts stay intact. No new arbitrary 3D, unverified lighting or silent re-asset of accepted SVGs.

### Q2 — Intentional motion beats with contact-preserving performance (critical artistic fix)
Implement a pure G3 performance sampler with four/several authored and reusable beats relative to source events, not film-specific hardcoded frames:
1. **Attention and anticipation**: lead gaze/head subtly toward held prop, torso and hip prepare for motion with controlled timing, free hand balances the body. No pointless wobble or animated movement without purpose.
2. **Lift/hold action**: intentional ease-in/acceleration/ease-out, subtle torso counter-rotation/hip transfer while real held object follows its authored path exactly, independent head/eyes intention via supported art (no fake gaze control if unsupported), non-held hand secondary motion.
3. **Handoff/release**: exactly preserve source frame and Rapier initial pose; fingers open at ownership transfer, avoid prop telekinesis and cross-layer clipping; arm, shoulder and head initiate believable recovery instead of frozen-wrist hover.
4. **Follow-through and settle**: short overshoot/damped settle in torso/head/free-hand, bounded timing, no gratuitous continuous bouncing. Use keyframed deterministic interpolation, no run-time state.
Iterate on *both* characters to avoid one-scene overfit. Candidate small ranges for calibration only (not automatic PASS): torso 1–5 degrees, hip displacement 2–10 stage px, head 2–8 degrees, off-hand follow 4–16 stage px. Record chosen values per actor/shot, keep existing world-contact/foot/IK constraints; reduce only optional movement if constraints fail. Never exceed original fail-closed policy to force style.
