Scaffold a new composition project (hyperframes init v0.9.30)

USAGE hyperframes init [OPTIONS] [NAME]

ARGUMENTS

  NAME    Project name

OPTIONS

            -e, --example=<example>    Example name (e.g. warm-grain, swiss-grid, blank)                                                                                                                                                                                                                                                                                                                                                                                                                                                                  
          -t, --template=<template>    [renamed] Use --example instead.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   
                -v, --video=<video>    Path to a video file (MP4, WebM, MOV)                                                                                                                                                                                                                                                                                                                                                                                                                                                                              
  -V, --video-legacy=<video_legacy>    [renamed] Use --video (or -v) instead of -V.                                                                                                                                                                                                                                                                                                                                                                                                                                                                       
                -a, --audio=<audio>    Path to an audio file (MP3, WAV, M4A)                                                                                                                                                                                                                                                                                                                                                                                                                                                                              
                  --skip-transcribe    Skip whisper transcription                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         
                    --keep-original    Copy the --video file as is, without converting it to H.264 MP4                                                                                                                                                                                                                                                                                                                                                                                                                                                    
                    --model=<model>    Whisper model for transcription (e.g. tiny.en, base.en, small.en, medium.en, large)                                                                                                                                                                                                                                                                                                                                                                                                                                
              --language=<language>    Language code for transcription (e.g. en, es, ja). Filters out non-target speech.                                                                                                                                                                                                                                                                                                                                                                                                                                  
                  --non-interactive    Disable interactive prompts (for CI/agents)                                                                                                                                                                                                                                                                                                                                                                                                                                                                        
                            --agent    Deprecated alias; default init is the centered blank                                                                                                                                                                                                                                                                                                                                                                                                                                                               
                      --skip-skills    Skip installing missing core AI skills (also HYPERFRAMES_SKIP_SKILLS=1)                                                                                                                                                                                                                                                                                                                                                                                                                                            
                         --tailwind    Add Tailwind CSS browser-runtime support                                                                                                                                                                                                                                                                                                                                                                                                                                                                           
          --resolution=<resolution>    Canvas resolution preset: landscape (1920x1080), portrait (1080x1920), landscape-4k (3840x2160), portrait-4k (2160x3840), square (1080x1080), square-4k (2160x2160), landscape-1440p (2560x1440), portrait-1440p (1440x2560), square-1440p (1440x1440). Aliases: 1080p, 4k, uhd, 1440p, qhd, 1080p-square, square-1080p, 4k-square, 1440p-portrait, 1440p-square. Default: a --video clip's own shape as it plays, 1080 on the short side (4:3 -> 1440x1080), else the template's dimensions (typically 1920x1080).
                    --skill=<skill>    Owning authoring skill slug (e.g. hyperframes). Stamped into hyperframes.json so every render of this project is attributed to it on usage telemetry, without re-passing --skill on each render. Ignored unless it is a slug.
